## Proyecto integrador

Construir un entorno virtualizado de laboratorio con Windows Server y Ubuntu:
- Dominio Active Directory.
- Usuarios, grupos y unidades organizativas.
- DNS, DHCP y GPO.
- Redes virtuales y segmentación.
- Procedimientos de backup y recuperación.

## Escenarios de troubleshooting

1. Usuario no puede iniciar sesión.
2. Una GPO no se aplica.
3. Una VM no tiene conectividad.
4. Datastore con poco espacio.
5. VM con CPU o memoria saturada.
