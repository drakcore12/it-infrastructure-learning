## Flujo de trabajo por laboratorio

1. Leer documentación oficial y definir el objetivo.
2. Preparar el entorno y registrar el estado inicial.
3. Ejecutar la práctica.
4. Verificar el resultado con comandos, capturas o pruebas reproducibles.
5. Registrar errores, causa raíz y solución.
6. Guardar evidencias sin secretos ni información privada.

## Estándar de documentación

Cada laboratorio debe incluir:
- Objetivo y alcance.
- Prerrequisitos.
- Arquitectura o diagrama.
- Procedimiento.
- Comandos y configuraciones relevantes.
- Validación y resultados.
- Troubleshooting.
- Conclusiones.

## Seguridad

- No publicar contraseñas, tokens, claves privadas, archivos `.env` ni datos de empresas.
- Usar exclusivamente laboratorios propios o autorizados.
- Controlar costos cloud y eliminar recursos de prueba.
- Los snapshots no sustituyen los backups.
